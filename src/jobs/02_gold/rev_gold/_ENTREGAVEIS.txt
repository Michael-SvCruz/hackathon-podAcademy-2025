## ✅ VALIDAÇÕES (4 Gates)

```
✅ Gate 1: Grain 1:1 CPF+SAFRA
   → count(*) == count(distinct cpf,safra)

✅ Gate 2: Nenhum NULL chaves
   → count(where cpf IS NULL OR safra IS NULL) == 0

✅ Gate 3: Distribuição OK
   → ~70% baixo risco, 30% em risco (esperado)

✅ Gate 4: Completude > 70%
   → atraso >60%, pagto >90% (esperado)
```
