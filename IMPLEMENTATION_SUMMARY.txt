🎯 O QUE FOI IMPLEMENTADO
────────────────────────────────────────────────────────────────────────────────

ABT v1 = bureau_full (spin) + SCORE_01 como feature principal

Estrutura:
  ├── CHAVES
  │   ├── num_cpf
  │   ├── safra
  │   └── dt_safra
  │
  ├── LABELS (NÃO features!)
  │   ├── flag_instalacao_int (decisão: 0/1)
  │   └── fpd_int (target risco: 0/1, observado SÓ em FLAG=1)
  │
  ├── FEATURES v1
  │   ├── score_01_adj (score histórico do banco)
  │   └── flag_score01_missing (flag de sentinela)
  │
  └── METADADOS + AUDITORIA

Validações Automáticas:
  ✓ Gate 1: Sem duplicatas
  ✓ Gate 2: FPD observado SÓ em FLAG_INSTALACAO=1 (CRÍTICO!)
  ✓ Gate 3: Chaves sem NULL
  ✓ Gate 4: FLAG tem 0 e 1
  ✓ Gate 5: FPD tem 0 e 1 (balanceado)
  ✓ Gate 6: Score_01 com cobertura > 90%

Anti-Leakage:
  ✗ FPD NUNCA como feature (é o target!)
  ✗ FLAG_INSTALACAO NUNCA como feature (é leakage!)
  ✓ Ambas incluídas SÓ para auditoria/swaps
