## 🎯 Decisões de Design

### ✅ Pagamento Features (36)
- COD_FORMA_PAGAMENTO breakdown (01, 02, 03, missing)
- Juros como POS + NEG_ABS (val_multa_juros não existe)
- Desconto flag + missing flag

### ✅ Atraso Features (36)
- FAIXA_AGING breakdown (0-30, 31-60, 61-90, >90, missing)
- FRAUDE/ACA/PCCR para M1, M3, M6 (não apenas M1)
- WO + PDD binary flags

### ✅ Temporal Windows
- M1: 1 mês
- M3: 3 meses
- M6: 6 meses
- Tudo ANTES de DT_SAFRA (sem leakage)

### ✅ Join Strategy
- LEFT JOIN (spine é v5)
- Preserva 1:1 cardinality
- NULLs preenchidos com 0
